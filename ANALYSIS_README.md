# Блок «Надёжность и новости по эмитенту»

Внизу страницы облигации выводится:
- **Оценка надёжности** (шкала 0–100) с разбором, как она посчитана;
- **Актуальные новости** по эмитенту.

Работает **полностью бесплатно, без ключей, регистраций и VPN**, прямо в браузере.

## Как это устроено

```
React (BondAIInsights) ──► aiApi.analyzeBond(bond)
                              ├─ надёжность: формула на JS (биржевые метрики)
                              ├─ новости: Google News RSS через CORS-прокси
                              └─ кэш: localStorage (24 ч)
```

### Надёжность (формула, без ИИ)
Балл складывается из объяснимых факторов (см. `reliability()` в
`src/api/aiApi.js`):
- уровень листинга MOEX (1/2/3),
- сектор (государственный / корпоративный),
- доходность к погашению (аномально высокая = риск),
- срок до погашения,
- ликвидность (число сделок).

Итог нормируется в диапазон 5–95 и переводится в метку **Высокая / Умеренная /
Низкая**. В интерфейсе есть раскрывающийся блок «Как считалась оценка» —
показывает вклад каждого фактора (удобно для защиты).

### Новости
Запрос вида `«<название бумаги> облигации»` уходит в **Google News RSS**. Браузер
не может читать чужой RSS напрямую (CORS), поэтому ленту скачивает сторонний
сервис **rss2json.com** (отдаёт готовый JSON с CORS); запасной путь — CORS-прокси
`allorigins.win` с разбором XML. Сервер посредника сам ходит за новостями, поэтому
VPN и регистрация не нужны.

## Запуск

Ничего настраивать не надо — просто:

```bash
npm start
```

Откройте любую облигацию → блок появится внизу. Первый расчёт по бумаге занимает
1–2 секунды (загрузка новостей), дальше берётся из кэша 24 часа.

## Настройки (в `src/api/aiApi.js`)

| Что | Где |
|-----|-----|
| Веса факторов надёжности | функция `reliability()` |
| Кол-во новостей | `MAX_NEWS` |
| Время жизни кэша | `CACHE_TTL_MS` |
| Поисковый запрос новостей | функция `fetchNews()` |

Сбросить кэш: в консоли браузера `localStorage.clear()`.

## Возможные нюансы

- **Сторонние сервисы новостей иногда тормозят/недоступны.** Надёжность это не
  ломает (она считается локально) — просто временно может не быть новостей. Код
  пробует rss2json, а при сбое — запасной прокси.
- Если позже захотите **настоящий ИИ-анализ** (генеративная оценка + умная
  выжимка новостей), это можно добавить отдельным провайдером; формула останется
  как прозрачная база.

> Оценка рассчитана по биржевым метрикам и не является инвестиционной
> рекомендацией — это стоит указать и в тексте диплома.
